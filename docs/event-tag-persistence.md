# 0.4.2 标签方案：历史验证

**本方案已由 [0.4.3 本地事件](local-events.md)取代，不再作为安装要求。**

2026-10-22，在 Immich 3.3.4 的样本环境完成 199 个事件、942 张照片的标签迁移；全部照片刷新元数据后，标签名称、成员、XMP 和原图校验和核验通过。当时样本目录可写。

验证发现：只读目录无法持久写入 XMP，重新提取元数据可能覆盖标签关联；连续标签操作还需要等待异步队列。因此标签方案要求目录写权限和管理员任务读取 key，但会在照片目录增加附属文件。

0.4.3 撤回这些要求：事件只存 Aura，原图只读，不再写标签。已有标签和 XMP 保留，避免误删其他元数据。历史通过标签持久性验证不代表 0.5 活动识别已经完成。
